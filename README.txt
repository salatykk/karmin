Бот студии KARMIN (@karminapp_bot)

Запуск на Windows: дважды щёлкните start.bat.
При первом запуске он сам установит всё нужное (нужен Python 3.10+).
Бот работает, пока открыто окно. Закрыли окно — бот остановился.

Настройки в файле .env:
  BOT_TOKEN — токен бота (никому не показывайте)
  ADMIN_ID  — id администратора, которому приходят заявки
